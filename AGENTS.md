# Repository working instructions

- Research in English; write user-facing content in Traditional Chinese (zh-TW).
- This repository contains clinical research and design documentation. Do not label proposed features as implemented or clinically validated.
- Read `README.md` and the relevant chapter before editing. Keep `archive/` as an immutable source snapshot.
- Preserve primary-source citations, dates, populations, outcomes, and evidence limitations. Verify medical, policy, and software claims against current primary sources when changing them.
- Distinguish clinical guidance, Taiwan regulatory or reimbursement rules, and local implementation.
- Keep confirmed disease, possible abnormality, predicted risk, missing data, and action completion separate.
- Do not generate missing clinical values, questionnaire responses, or unsupported diagnoses. Use explicitly fictional examples.
- Preserve clinician review and shared decision-making in any proposed treatment workflow.
- Keep real patient information, credentials, and private clinical exports out of the repository.
- When references or source versions change, update the relevant chapter, source index, provenance, and changelog consistently.
- For documentation edits, check Markdown structure, relative links, and preservation of source meaning. Add executable tests only for actual code behavior.
